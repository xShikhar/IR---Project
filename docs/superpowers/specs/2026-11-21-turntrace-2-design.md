# TurnTrace 2 design

The user authorized implementing the discussed upgrade end to end in IR-Project, retaining React and the existing Node backend. This directory is an independent copy of the midterm checkout at d0022603ebd9181f21e0e406cfd4a2d72af79104; IR-Assignment remains untouched. Local development and delivery are requested, not hosted publication.

## Approach
Keep all original index, scoring, conversation, and evaluation modules as the frozen midterm baseline. Add a v3 application layer with structured weighted retrieval, an independent topic graph, snapshot previews, actionable clarification, feedback, comparison, snippets, diversity, and experiment exports. This is preferable to rewriting the IR engine or changing the original experiment silently.

## Boundaries
- Search service: `server/src/v3/search.js`, `createSearchService(index)` exposes async `search(query, options)`, sync `interpretations(query)`, `status()`. Options: `{model:'hybrid'|'bm25'|'cosine'|'semantic',topK,topic:{id,title,entityTerms:string[]}, feedback:{relevant:string[],irrelevant:string[],pinned:string[]},excludedTerms:string[],diversity:boolean,domain:string|null}`. Return `{results,trace}`. Results preserve original docId/title/body/domain/score and add snippet, highlights, origins, breakdown. Interpretations return `{id,title,terms:string[],docCount,example}` based on corpus article identities. Explicit weighted inputs affect scores. No gold labels in runtime. Neural availability is exposed honestly.
- Session orchestration: `server/src/v3/workspace.js`, `createWorkspace(index,searchService)` with async `turn(query,options)`, `snapshot()`, `selectTopic(id)`, `feedback(docId,action)`, `undo()`, `reset()`. Maintains topic-specific memory, selected interpretations and relevant/irrelevant/pinned IDs. Preview uses clones; turn commits once. Clarification uses matching interpretation IDs; no corpus-free fabricated options.
- API: preserve /api/chat baseline. Add /api/v3/session (GET/DELETE), /api/v3/search, /api/v3/topic, /api/v3/feedback, /api/v3/undo, /api/v3/preview, /api/v3/compare, /api/v3/scenarios, /api/v3/evaluation, /api/v3/export. Requests use sessionId. Search returns `{results,trace,session,clarification,comparison?}`. Session `{id,activeTopicId,topics:[{id,title,entityTerms,aspects,turnCount,feedback}],turns:[],canUndo}`. Clarification `{question,options:[{id,title,terms,docCount,example}]}` or null.
- Frontend: React research workspace with topic sidebar, central conversation/evidence, right explanation inspector, comparison and experiments views. Responsive slate/white canvas, indigo accent and lime highlights, proper loading/error/empty states. All controls use real endpoints; support keyboard and accessible labels.
- Evaluation: preserve old artifacts. Add separate v3 runner, label coverage reports, raw-vs-midterm-vs-v3 same-turn comparisons, behavior scenarios for resumption/clarification/feedback. Public report separates inherited LLM qrels, synthetic behavior cases, and human validation not yet performed. Missing judgments are exposed.

## Delivery
Reproducible npm scripts, cached dataset/model instructions, local production server, demo scenarios, honest research report and references, submission ZIP containing source+dataset and PDF when verified. No push or publication to external services. Tests cover isolation, preview immutability, topic resumption, correction undo, ambiguous interpretation, actual weighted ranking, filters, missing semantic cache, and invalid inputs. Original 83 tests remain supported.
